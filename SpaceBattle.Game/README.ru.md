# SpaceBattle Desktop

Наблюдайте за автономным боем флотов в Silk.NET/OpenGL-клиенте. Он запускает общую C#-симуляцию на SKECS. Вы управляете камерой и скоростью симуляции; кораблями управляет ИИ.

[Обзор SpaceBattle](../docs/space-battle/README.ru.md) | [Текущий отчёт](../docs/space-battle/REPORT.ru.md) | [Техническое руководство](DEVELOPMENT.ru.md)

## Запуск

Из корня репозитория, с .NET 8 и устройством, поддерживающим OpenGL 3.3:

```powershell
dotnet build SpaceBattle.Game/SpaceBattle.Game.csproj -c Release
./SpaceBattle.Game/bin/Release/net8.0/SpaceBattle.Game.exe
```

По умолчанию на сторону приходятся 96 эскортных кораблей и три носителя: всего 198 кораблей. Используются LightSwarm, разреженная расстановка, послойная тактика групп, прикреплённые орудия и круговая физика. Истощённые флоты получают угловые warp-подкрепления. Правила описаны в [руководствах по геймплею](../docs/space-battle/README.ru.md#текущий-геймплей).

Полезные параметры:

| Параметр | Назначение |
| --- | --- |
| `--seed 7331` | Повторить начальный сценарий с заданным seed |
| `--ships-per-team 96` (также `--ships`) | Начальное число эскортов на сторону, без носителей |
| `--finite` | Отключить бесконечные warp-подкрепления |
| `--width 1440 --height 900` | Размер окна; минимум 960 × 540 |
| `--statistics` | Открыть подробную статистику |
| `--colliders` | Сразу показать контуры столкновений |
| `--follow-ship 22` | Начать слежение по серийному номеру корабля |

`--ships 2048 --legacy-deployment` — намеренно плотный стресс-сценарий, а не стандартная игра.

## Управление

| Действие | Ввод |
| --- | --- |
| Пауза / продолжение | Пробел или кнопка HUD |
| Скорость симуляции | + / − или кнопки HUD |
| Перезапуск боя с тем же seed | R или кнопка HUD |
| Вписать арену | Home или кнопка HUD |
| Панорамирование | WASD / стрелки, перетаскивание средней или правой кнопкой |
| Приблизить к курсору | Колесо мыши |
| Выбрать корабль | Левая кнопка |
| Следить за выбранным кораблём | C или кнопка прицела |
| Контуры столкновений | F2 или кнопка рамки |
| Статистика | F3 или кнопка диаграммы |

Слежение удерживает в кадре наблюдаемый корабль и его живую цель. При гибели камера переходит к известному живому владельцу смертельного снаряда, иначе к ближайшему выжившему. Ручное движение камеры, выбор другого корабля, Fit или перезапуск отменяют слежение. Камера не влияет на бой.

Статистика разделяет время симуляции, популяции, боевые счётчики и память хранилищ. Mean усредняет последние 600 тиков симуляции (10 секунд при 60 Hz), включая физику и commit. Capture и рендер остаются за пределами таймера. Для сравнения используйте [отчёт игрового режима с окнами HUD](../docs/space-battle/GAME_REPORT.ru.md): среднее всего конечного боя относится к другой нагрузке и периоду.

## Кадры и диагностика

[Техническое руководство](DEVELOPMENT.ru.md) описывает захват framebuffer, визуальные проверки, проверку статистики и CPU/GPU-профилирование. [Происхождение ассетов](Assets/PROVENANCE.ru.md) фиксирует контракт спрайтов. [Инструменты сцен](../tools/space-battle/scenes/README.ru.md) находят и записывают реальные боевые эпизоды.

Новые кадры и профили сохраняйте в свежий каталог `Benchmarks.Local/tmp`. Завершайте рендеринг, сборки и проверки до измерения бенчмарка.
