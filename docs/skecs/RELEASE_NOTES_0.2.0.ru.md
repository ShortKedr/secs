# SKECS 0.2.0 — Branch

В SKECS 0.2.0 несовместимо изменены имя продукта и идентификаторы публичного
API относительно SECS 0.1.0. Переименование происходит до версии 1.0.0.

## Миграция

- Замените пакет `ShortKedr.SECS` на `ShortKedr.SKECS` версии `0.2.0`.
- Измените директивы C# с `using SECS;` на `using SKECS;`.
- Обновите путь к проекту с `SECS/SECS.csproj` на
  `SKECS/SKECS.csproj`, а solution — с `SECS.sln` на `SKECS.sln`.
- В Unity удалите `SECS.dll` и импортируйте `SKECS.dll`.

Старые пакет и пространство имён не являются псевдонимами совместимости.
Потребители, оставшиеся на старом API, могут использовать опубликованный выпуск
[`secs-v0.1.0` Cone](https://github.com/ShortKedr/skecs/releases/tag/secs-v0.1.0)
с исходными пакетом, Unity ZIP, контрольными суммами и JSON проверки. Эти файлы
выпуска и результаты проверки относятся только к SECS 0.1.0.
