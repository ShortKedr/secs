# Внутренние шаблоны задач SECS

[Карта документации](../../README.ru.md) · [План развития](../DEVELOPMENT_PLAN.ru.md)

Статус: задания для будущей реализации, подготовленные 12 октября 2026 года.
Это рабочие шаблоны для сопровождающего библиотеку. Они не описывают готовые
возможности SECS и не нужны для установки или запуска текущего API.

Перед использованием сверяйте шаблон с исходниками и актуальным планом,
уточняйте границы задачи и критерии приёмки. Указанные в шаблоне изменения
тестов и бенчмарков относятся к реализации новой возможности. Миграция
SpaceBattle рассматривается отдельно в [сопутствующих изменениях](../RELATED_CHANGES.ru.md).

| Шаблон | Зависимости и результат |
| --- | --- |
| [Fixed](03_FIXED.ru.md) | Числовой CPU-эталон и проверенный контракт арифметики. |
| [Time slicing](02_TIME_SLICING.ru.md) | Последовательный runner после фиксации числового контракта. |
| [Многопоточность](04_MULTITHREADING.ru.md) | Параллельный исполнитель того же runner после последовательной приёмки. |
| [SIMD](01_SIMD.ru.md) | Числовые kernels со скалярным fallback; базовый chunk API может развиваться независимо. |

Номера файлов — идентификаторы шаблонов, а не порядок выполнения.
Очередность и общий контракт определяет [план развития](../DEVELOPMENT_PLAN.ru.md).
Для GA используйте отдельные [спецификацию и план](../ga/README.ru.md).
