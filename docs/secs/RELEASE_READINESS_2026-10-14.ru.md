# Готовность первого релиза SECS на 2026-10-14

Статус: **выпуск остановлен**. Кандидат `0.1.0 — Cone` подготовлен локально, но
условия приёмки из [ТЗ](RELEASE_PREPARATION.ru.md) пока не выполнены полностью.
Этот документ фиксирует проверенное состояние, а не заменяет результаты
релизного CI и проверку опубликованных файлов.

## Подтверждено локально

- Ядро собирается для `netstandard2.0`, `netstandard2.1` и `net8.0` без
  предупреждений; `SECS.Tests` проходит 16/16 тестов на Windows.
- `ShortKedr.SECS.0.1.0.nupkg` содержит три сборки ядра, MIT-лицензию, README,
  нужные зависимости и метаданные версии. Проверка
  [`verify_package.py`](../../tools/release/verify_package.py) проходит для
  локального пакета. Его `RepositoryCommit` указывает на текущий `HEAD`, но
  пакет собран из незакоммиченного рабочего дерева: это ещё не доказательство
  происхождения от релизного коммита.
- Потребители из [`tools/release-consumers`](../../tools/release-consumers)
  установили именно локальный пакет (SHA-256 восстановленной копии совпал) и
  выполнили `CreateEntity → Query → Get → Dispose` на Windows x64: .NET 8
  (`net8.0`, SDK 8.0.426), .NET 10 (`net10.0`, SDK 10.0.204), .NET Framework
  4.8-совместимая среда (`net48`, SDK 8.0.426) и Godot 4.5 .NET
  (`4.5.stable.mono.official.876b29033`). Для `net48` транзитивные пакеты
  взяты из локального офлайн-источника.
- Скрипты создания и проверки Unity ZIP сверяют DLL байт-в-байт с пакетом.
  Финальный ZIP получает список точных Unity Editor/backend/OS только из шести
  успешных записей одного запуска CI. Положительная и отрицательная проверки
  формата выполнены на **синтетических** записях; они не доказывают запуск Unity.
- [Инструкции установки](INSTALL.ru.md) проверены на парность команд и локальные
  ссылки отдельно от остальных документов.

Текущий пользовательский запрет на команды, меняющие удалённое состояние,
сохраняется. Поэтому публикация и настройка GitHub выполняются только после
изменения этого ограничения самим пользователем; локальная подготовка не
означает разрешения на push, регистрацию runner или создание Release.
