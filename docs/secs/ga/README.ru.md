# Спецификация и план GA SECS

Пакет от 12 октября 2026 года задаёт требования к выполнению систем SECS с графическим ускорением (Graphics Accelerated, GA). Редакция 0.2 учитывает исследование текущей симуляции SpaceGame. Статус: техническое задание и план; GPU-исполнитель ещё не реализован.

[Карта документации](../../README.ru.md) · [Текущий API SECS](../README.ru.md)

Целевой принцип: одна симуляция, один исходник систем, побитово одинаковые CPU и поддерживаемый GPU результаты; возможности устройства меняют способ выполнения, сохраняя игровую логику.

ТЗ описывает контракты, план — порядок работ и приёмку, правила — требования к автору системы, исследование — игровые причины этих требований. Ни один документ пакета не является инструкцией запуска готового GPU backend.

- [Техническое задание](SPEC.ru.md) — контракты систем, IR, чисел, runner, Slang/runtime, artifacts, startup fallback и платформ.
- [План реализации](IMPLEMENTATION_PLAN.ru.md) — задачи GA 00–12, зависимости, владение файлами, проверки и критерии выпуска.
- [Правила написания систем](GUIDELINES.ru.md) — обновляемый C# subset, диагностики, требования к доступам и безопасному fallback.
- [Исследование SpaceGame](SPACEGAME_REVIEW.ru.md) — снимок исходников от 12 октября 2026 года: реальные фазы, контекст и ресурсы, собственная физика, domain order, spatial queries, checksum и desktop/Web host.

GA переиспользует [общую числовую и runner работу](../DEVELOPMENT_PLAN.ru.md) и [план тестов детерминизма](../../SECS_DETERMINISM_PLAN.ru.md). Приоритет первого прототипа — exact CPU/GPU исполнение одной системы. Игровая приёмка расширена до шести fixtures с explicit context, resources, ordered apply и capacity arbitration. Desktop приёмка требует Windows, Linux и macOS; Android/iOS и дополнительные API квалифицируются отдельными этапами. Поддержка устройства через CPU не считается проверкой GPU compute.

При расширении subset одновременно обновляются compiler/analyzer registry, lowering, tests и guideline. Любое изменение числовой или событийной семантики требует новой версии контракта.
