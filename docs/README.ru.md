## Исторические названия

Раньше проект назывался SECS. В сохранённых отчётах о бенчмарках, исходных
результатах, снимках экрана и хешах оставлены исходные метки `SECS`, чтобы
сохранить их идентичность и историю проверки. Эти метки относятся к измеренной
исторической версии; в текущей документации и API используется SKECS.

## Space Battle

[Карта игровой документации](space-battle/README.ru.md) охватывает системы
