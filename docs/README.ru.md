# Карта документации

[Обзор проекта](../README.ru.md)

Выберите маршрут ниже. Руководства по API описывают текущий код; планы —
требования к будущей работе; исторические отчёты — версии и измерения,
указанные в самом отчёте.

## Использование SECS

- [Руководство библиотеки](secs/README.ru.md): запросы, системы, владение и время жизни.
- [Оптимизации среды выполнения](SECS_OPTIMIZATION.ru.md): уже реализованные прямое создание, аксессоры, сохранённое хранилище и диагностика.
- [Пример](../SECS.Sample/Program.cs) и [тесты](../SECS.Tests): исполняемые примеры и текущие контракты.

## Развитие библиотеки

| Документ | Статус и назначение |
| --- | --- |
| [План тестов детерминизма](SECS_DETERMINISM_PLAN.ru.md) | Предлагаемые канонические снимки, replay-сценарии и матрица CI. [Пример workflow](secs-determinism.example.yml) неактивен и запускает только существующие тесты. |
| [План развития ядра](secs/DEVELOPMENT_PLAN.ru.md) | Предлагаемые контракты Fixed, time slicing, SIMD и параллельного runner. |
| [Сопутствующие изменения](secs/RELATED_CHANGES.ru.md) | Границы тестов, бенчмарков и отдельно обосновываемой миграции потребителей. |
| [Пакет спецификации GA](secs/ga/README.ru.md) | Предлагаемый общий CPU/GPU-контракт, этапы реализации и критерии квалификации. |
| [Внутренние шаблоны задач](secs/prompts/README.ru.md) | Исходные задания для будущей реализации; не установленный API и не инструкции пользователю по настройке. |

В текущем SECS запросы и вызовы систем последовательны. Наличие этих планов
не означает, что числовые типы, scheduler, compiler или GPU backend уже есть.
Пакеты развития и GA пока имеют только русские оригиналы.

## Space Battle

[Карта игровой документации](space-battle/README.ru.md) охватывает системы
симуляции, физику, флоты, ассеты, desktop/Web-хосты и воспроизведение.
Начинайте с неё для игровой реализации и истории диагностики.
