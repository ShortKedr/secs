# SECS release artwork

The Cone, Branch, and Canopy illustrations are original project artwork
generated with the built-in `image_gen.imagegen` tool. The visual references
were the existing [squirrel-and-cone emblem](../shortkedr-ecs-emblem.png) and
[isolated cone](../shortkedr-ecs-cone.png); neither source file was changed.
The three output PNGs are 1672 × 941 pixels each.

All three prompts requested a wide, text-free release illustration in the
emblem's layered vector-cut style: plum-purple squirrel and cedar scales,
electric-cyan ribbons, coral highlights, and a midnight-indigo background.
The left side stays quiet so a real release title can be added later as text.

| File | Distinct prompt direction |
| --- | --- |
| [cone.png](cone.png) | A squirrel curled around a compact luminous cedar cone; the beginning of the series. |
| [branch.png](branch.png) | The same squirrel climbing a growing, geometric cedar branch; structure and expansion. Cone artwork supplied as a style reference. |
| [canopy.png](canopy.png) | The squirrel overlooking a broad mature cedar canopy with many cones; scale and stability. Cone and Branch artwork supplied as style references. |

The artwork depicts planned release names. It does not certify that any of
those versions have been published or that the planned features are complete.
