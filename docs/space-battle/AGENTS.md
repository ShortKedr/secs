# Space Battle report contract

`REPORT.md` and `REPORT.ru.md` are generated from `tools/space-battle/analyze_current.py`. Update that generator first, then regenerate both reports from the same saved campaign. Do not hand-edit only one language or replace the reports with a new outline when the measured profile matrix changes.

Keep this section order in both current reports: framework revisions, reading the results with the colour scale, validation, tick time, opening windows, simulation state and stages, HUD windows, data provenance, reproduction, history and related documents. A new measurement may add a clearly named section, but a profile change alone does not remove these sections or their existing evidence.

Use the shared nine-step scale in `../benchmarks/COLORS.md` via `tools/benchmark_colors.py`: local SVG markers in comparable timing and managed-allocation cells, and the same palette in comparison charts. Compare five ECS implementations only within the same profile, metric, timer scope and window. Do not colour checksums, entity counts, event counts, parameters, or stage shares. State that colour shows observed effect size rather than statistical significance. Keep the visible legend and the link to the comparison rules in both languages.

The current benchmark contains exactly one real-game workload: profile `high`, preset `game`, and gameplay `ChurnMultiplier=2`, measured across the five ECS implementations. Do not add synthetic churn, diagnostic profiles, an inert entity pool, or a pre-Step churn hook. The report generator must reject a current campaign with any other profile set or workload configuration; do not silently filter extra profiles or relabel old measurements as the current campaign. Keep the older `low/nominal/high` gameplay-churn matrix in its dated finite-battle archive and do not compare its timings numerically with the current campaign. Preserve the outer-timer versus HUD/stage-timer distinction. Do not retain a synthetic-experiment section in either current report.

Before presenting an update, run the report generator against the saved campaign, check both languages, verify that the colour markers and section order remain present, and run `tools/space-battle/test_analyze_current.py`. Regeneration from published JSON does not itself verify local tick CSV files; report that boundary accurately.
