# SpaceBattle

SpaceBattle — бой флотов под управлением ИИ и реалистичная нагрузка для сравнения ECS. Desktop и браузер используют общую C#-симуляцию; headless запускает её на SECS, LeoECS Lite, LeoECS Classic, Morpeh или StaticEcs.

## Текущий геймплей

Интерактивные клиенты начинают с 96 эскортных кораблей и трёх носителей на сторону. Корабли сражаются сами; пользователь управляет камерой, скоростью и инструментами наблюдения. Истощённые флоты получают warp-подкрепления без сброса выживших. У headless теперь два явных режима: `game` повторяет состав, расстановку и подкрепления игры по умолчанию; `benchmark` сохраняет прежний конечный бой.

## Воспроизведение бенчмарка

Выполняйте команды из корня репозитория. Соберите и проверьте код до замера; завершите другие сборки, рендеринг, профилировщики и браузерные проверки перед измерением. Не смешивайте конфигурации или ревизии.

Каждая полная серия измеряет пять ECS на low, nominal и high churn: по 108000 измеряемых тиков и 600 отдельных прогревочных тиков на случай. При замене опубликованных данных запускайте серии последовательно:

```powershell
./tools/space-battle/run-suite.ps1 -OutputDirectory docs/space-battle/current
```

Добавьте `-Preset game -OutputDirectory docs/space-battle/game-current`, чтобы измерить настройки игры по умолчанию. `-SkipBuild` использует подготовленный Release-host. Короткие `-Ticks`/`-Warmup` подходят для smoke-проверки; задавайте им отдельный каталог вывода. Оба отчёта содержат полный Step, суммарное время, девять стадий и окна по 600 тиков с тем же таймером, что в desktop HUD.

Прежние замеры `predictive-neutral-v1` использовали Aether и старые правила боя. Они хранятся отдельно: [отчёт 2026-10-11](REPORT_2026-10-11.ru.md), [архив методики](BENCHMARK_METHOD_2026-10-11.ru.md), [исторический каталог систем](SYSTEMS.ru.md). Они не подтверждают производительность текущих исходников. [Обложка](COVER.ru.md) — иллюстрация, а не замер.
