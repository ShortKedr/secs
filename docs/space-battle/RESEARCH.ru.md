# Исследования SpaceBattle

[Текущий геймплей и запуск](README.ru.md) | [Текущая измеренная кампания](REPORT.ru.md)

Каждое исследование подтверждает результат только для записанного снимка исходников, сценария и среды. Изменения игры не обновляют прежние замеры. Проверки before/after внутри одной среды не доказывают кроссплатформенный детерминизм; часы стадий диагностики не равны FPS клиента.
