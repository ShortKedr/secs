# SpaceBattle Web

Браузерный клиент общей C#-симуляции флотов на SECS. Production использует .NET 8 Mono AOT WebAssembly; Canvas рисует сцену. Корабли сражаются сами, пользователь управляет камерой и скоростью.

[Демо](https://shortkedr.github.io/secs/) | [Демо на русском](https://shortkedr.github.io/secs/?lang=ru) | [Обзор SpaceBattle](../docs/space-battle/README.ru.md) | [Текущий отчёт](../docs/space-battle/REPORT.ru.md)

Ссылка ведёт на цель развёртывания. Локальные изменения её не обновляют; опубликованная сборка может отличаться от этого checkout.

## Локальный запуск

Требования: Node.js, Python для статического сервера, .NET SDK 8.0.4xx, выбранный [global.json](global.json), и workload `wasm-tools` для него. Скрипт использует установленный SDK и не устанавливает workload.

Из корня репозитория:

```powershell
npm ci --prefix tools/web --cache Benchmarks.Local/tmp/npm-cache
$publish = "Benchmarks.Local/tmp/web-local-" + [guid]::NewGuid().ToString("N")
./tools/build-space-battle-web.ps1 -OutputDirectory $publish -ArtifactsDirectory ($publish + "-build") -BasePath /
python -m http.server 8000 --directory "$publish/wwwroot"
```

Откройте [localhost:8000](http://localhost:8000/) или [русский интерфейс](http://localhost:8000/?lang=ru). Для следующей сборки выберите свежие каталоги вывода и сборки. `-Interpreter` доступен для локальной диагностики; сравнения производительности используют production AOT.

## Управление

| Действие | Ввод |
| --- | --- |
| Пауза / продолжение | Пробел или кнопка паузы |
| Перезапуск | Reset; смена seed или профиля тоже перезапускает бой |
| Скорость | Кнопки скорости |
| Панорамирование / зум | Перетаскивание сцены / колесо; на touch — перетаскивание и pinch |
| Вписать арену | Fit |
| Выбрать корабль | Клик / касание |
| Следить за выбранным кораблём | C или кнопка прицела |
| Контуры столкновений | F2 или кнопка пунктирного квадрата |
| Статистика | Кнопка диаграммы внизу |
| Полный экран | F или кнопка fullscreen |
| Язык | EN/RU или `?lang=ru` |

Ручное движение/зум, Fit, снятие выбора и reset отменяют слежение. Камера и контуры не влияют на бой. По умолчанию на сторону приходятся 96 эскортов и три носителя, с бесконечными угловыми подкреплениями; см. [текущий геймплей](../docs/space-battle/README.ru.md#текущий-геймплей).

Профили **low**, **nominal** и **high** задают интенсивность боя: множитель 0,5, 1 и 2. Он меняет паузы между выстрелами, интервалы производства на носителях и длительность ускорения. Число кораблей он напрямую не задаёт, а нагрузка не растёт строго вдвое: из-за иного хода боя меняются потери и подкрепления. Смена профиля начинает новый бой.

Нижняя строка и панель статистики описывают текущий браузерный запуск. Render FPS, ticks/s, Step time и память имеют разные области измерения; они не взаимозаменяемы с desktop headless-замерами.
